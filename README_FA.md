# 🛡️ اسکنر آی‌پی و دامنه کلودفلر

**یک ابزار قدرتمند برای اسکن دامنه‌ها و آی‌پی‌های پشت Cloudflare، مناسب برای شناسایی، تحلیل و بررسی پیکربندی‌های Cloudflare Worker.**

---

# 🚀 معرفی

**Cloudflare IP & Domain Scanner** یک ابزار سبک اما قدرتمند برای شناسایی و تحلیل دامنه‌ها و آی‌پی‌های محافظت‌شده توسط **Cloudflare** است.

برخلاف اسکنرهای عمومی، این پروژه به‌طور ویژه برای محیط‌های Cloudflare طراحی شده و اطلاعات دقیقی از جمله موارد زیر را ارائه می‌دهد:

* پورت‌های باز
* سرویس‌های در حال اجرا
* رکوردهای DNS
* وضعیت SSL/TLS
* تشخیص Cloudflare
* اطلاعات امنیتی
* اطلاعات شبکه

این ابزار با **تمام کانفیگ‌های Cloudflare Worker** سازگار بوده و گزارش‌هایی منظم و ساختاریافته برای تحلیل امنیتی تولید می‌کند.

> ⚡ تنها کافی است دامنه یا آی‌پی هدف را وارد کنید تا اسکنر تمام اطلاعات موردنیاز را جمع‌آوری کند.

# 🚀 نحوه استفاده

### اسکن معمولی

```bash
python scanner.py -t example.com
```

### اسکن کامل

```bash
python scanner.py -t example.com --full
```

### ذخیره گزارش

```bash
python scanner.py -t example.com -o report.json
```

### حالت مخصوص Worker

```bash
python scanner.py -t worker.example.com --worker
```

---

# ⚙️ پارامترهای خط فرمان

| پارامتر          | توضیح                                  |
| ---------------- | -------------------------------------- |
| `-t`, `--target` | دامنه یا آی‌پی هدف                     |
| `-p`, `--ports`  | محدوده پورت‌ها (مثال: `1-1000`)        |
| `-f`, `--full`   | اسکن کامل همراه با بررسی‌های امنیتی    |
| `-o`, `--output` | ذخیره گزارش در فایل                    |
| `-w`, `--worker` | فعال‌سازی حالت مخصوص Cloudflare Worker |
